Scripts that make development a little easier

## Setup

1. Navigate to the directory containing the scripts and make them executable.

- `chmod +x git-*`: Makes all of the scripts executable.
- `chmod +x git-example-script`: Makes a specific script with name "git-example-script" executable.

2. Add the directory containing the scripts to your PATH variable.
3. Run the script with `git-example-script` or `git example-script`. If you use the latter, git will automatically search for the custom command in your PATH.
